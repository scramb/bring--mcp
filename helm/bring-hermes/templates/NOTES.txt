Clients sign in via OAuth with their own Bring! account (login page /login).

{{- if .Values.ingress.enabled }}

Reachable via Ingress:

  {{- $scheme := "http" }}
  {{- if $.Values.ingress.tls }}{{ $scheme = "https" }}{{- end }}
  {{- range .paths }}
  {{ $scheme }}://{{ .host }}{{ $.Values.config.mcpPath }}
  {{- end }}
{{- end }}
{{- else if .Values.httpRoute.enabled }}

Reachable via Gateway API HTTPRoute (attached to: {{ range $i, $p := .Values.httpRoute.parentRefs }}{{ if $i }}, {{ end }}{{ $p.name }}{{ end }}):
{{- range .Values.httpRoute.hostnames }}
  https://{{ . }}{{ $.Values.config.mcpPath }}
{{- else }}
  (no hostnames set — the route matches all hostnames on its Gateway listener)
{{- end }}
{{- else }}

No Ingress or HTTPRoute is enabled. Port-forward to reach the service locally:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "bring-hermes.fullname" . }} 8080:{{ .Values.service.port }}

Then the MCP endpoint is at:  http://127.0.0.1:8080{{ .Values.config.mcpPath }}
{{- end }}

Endpoints:
  POST {{ .Values.config.mcpPath }}   -> MCP (requires an OAuth access token)
  GET  /healthz       -> liveness (unauthenticated)
  GET  /readyz        -> 200 while the database is reachable, else 503

Using existing Secret: {{ .Values.existingSecret }}
(must contain keys: DATABASE_URL, TOKEN_ENCRYPTION_KEY)
